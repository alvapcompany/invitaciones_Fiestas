💡 ¿Cómo agregar un nuevo cliente por carpeta?

  1. Elige la categoría: Entra a XV/, Bodas/ o Fiestas/.
  2. Duplica la carpeta Plantilla y dale el nombre de tu cliente (ejemplo: XV/Valeria/ o Bodas/Sofia_y_Andres/).
  3. Reemplaza los archivos multimedia: Coloca sus fotos en fotos/ y su canción en musica.mp3.
  4. Vincula Google Sheets: En index.html, cambia GOOGLE_SHEETS_URL por el Apps Script de tu cliente.
  5. Sube con Git: Ejecuta git add ., git commit -m "nuevo cliente" y git push. ¡Estará en vivo en GitHub Pages al instante!
