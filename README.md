## 💼 Modelo White-Label para Clientes

Cada cliente tiene su propio generador de pases privado (`admin.html`) que:
- Solo solicita el nombre de la familia y número de pases.
- Genera el enlace personalizado con un clic.
- Permite compartir directamente por WhatsApp.
- **No muestra configuraciones técnicas, URLs de base de datos ni Google Sheets al cliente.**
